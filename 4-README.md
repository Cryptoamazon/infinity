# Infinity Phase 1
**Talk to the people you love. Hear their voice.**

A privacy-first mobile web vertical slice for Infinity. All profile metadata is stored in localStorage and recorded voice samples in IndexedDB. No backend, voice cloning, or avatar synthesis is included in Phase 1.

## Modules
- Visual identity guide
- Voice sample capture
- Persona + memory evidence
- Permissions and consent
- Export/delete controls

Version: v0.1.0
